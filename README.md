# Smart Helmet Accident Detection System

This project improves rider safety by preventing drunk driving,
ensuring helmet usage, and sending accident alerts.

## Components Used
ESP32
MPU6050
GPS Module
SIM800C GSM
IR Sensor
Alcohol Sensor
Shock Sensor

## Features
Helmet detection
Alcohol detection
Accident detection
SMS alert with GPS location
Emergency alert cancellation
